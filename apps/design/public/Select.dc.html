用法Usage

何时用When选项固定、3–15 个。2 个用分段控件或开关；更多或需要远程搜索时用异步搜索选择。For a fixed set of 3 to 15. Two options: a segment or switch. Many, or remote: the async search select.
排序Order按使用频率或逻辑顺序排，不按字母排“是 / 否”这类选项。Order by frequency or logic; don’t alphabetise things like Yes / No.
禁用项Disabled options保持可见并在 meta 里写原因，而不是直接隐藏。Keep them visible with the reason in meta rather than hiding them.
弹层Menu弹层脱离容器渲染，不被对话框裁切；下方空间不足时向上展开。The menu renders outside its container so dialogs don’t clip it, and opens upward when needed.

该做与不该做Do and don’t

该做Do
选项少而固定时用下拉。A select for a short, fixed set.
不该做Don’t
只有两个选项时不要用下拉，改用开关或分段控件。Don’t use a select for two options; use a switch or segment.

无障碍Accessibility

键盘Keyboard方向键移动，Enter 选择，Esc 关闭，Home / End 跳到首尾，输入首字母跳转。Arrows move, Enter selects, Esc closes, Home and End jump, typing a letter jumps to it.
角色Roles触发器是 button，菜单是 listbox，选项是 option 并带 aria-selected。The trigger is a button, the menu a listbox, each row an option with aria-selected.
