构成Anatomy

用户消息User message亚麻底气泡，右对齐，最宽 75%。A linen bubble, right-aligned, 75% wide at most.
Agent 消息Agent message不加气泡，直接排在纸面上，左侧墨色方块头像。No bubble; set on the page with an ink tile avatar.
执行步骤Steps默认收起为“用时 · 步数”；运行时展开当前步骤；失败的步骤保持展开。Collapsed to time and count by default; the current step opens while running; failed steps stay open.
引用Citations句末编号，悬停显示出处，点击在查看器中打开并高亮。数字、日期、条款必须带引用。Numbered at the end of a sentence; hover shows the source, click opens it highlighted. Figures, dates and clauses must cite.
确认卡片Confirmation card发送、分享、签署、删除只能由 Agent 起草，用户确认后执行。墨色描边。Send, share, sign and delete are drafted by the Agent and run only after the user confirms. Ink outline.

规则Rules

范围可见Visible scope输入框左下的范围标签写明 Agent 能看到哪些资料。A scope tag in the composer says what the Agent can see.
可以打断InterruptibleEsc 或停止按钮随时停止，已输出的内容保留，可以继续。Esc or Stop halts at any time; what’s written stays and can continue.
失败说原因Explain failures写明哪一步、为什么失败，并给出下一步。Say which step failed, why, and what to do next.
随时转人工Hand over每条回答下都有“交给团队”，转成一张任务。Every answer offers Hand to the team, which becomes a task.
