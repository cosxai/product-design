输入框Input

用法Usage

标签总在Always label每个输入框都有可见标签；占位文字只给示例，不代替标签。Every field has a visible label; the placeholder shows an example and never replaces it.
错误写解决办法Errors say how to fix错误文字写怎么改，而不只是“格式错误”。失焦后再校验，不在输入时打断。Say how to fix it, not just “Invalid format”. Validate on blur, not while typing.
搜索与复制Search and copy搜索框和复制框是单独的组件：内置防抖、清除、复制反馈。Search and copy fields are separate components with debounce, clear and copy feedback built in.
宽度Width宽度匹配预期内容长度：邮箱 320，验证码 6 格，名称占满。Match the expected content: 320 for email, six cells for a code, full width for a name.

该做与不该做Do and don’t

该做Do
可见标签 + 示例占位。A visible label with an example placeholder.
不该做Don’t
不要只用占位文字当标签。Don’t use the placeholder as the label.
