同一层级内容之间切换Switch between views at the same level

产品界面用下划线样式；营销页面用 pills 样式，选中项在黄色 field 上。Product UI uses the underline style; marketing sections use pills, with the active one on the yellow field.

用法Usage

何时用When同一对象的几种视图，比如项目的概览、文档、当事人。切换不改变数据。Views of the same object, such as a project’s Overview, Documents and Parties. Switching changes no data.
数量Count2 到 7 个。更多时把次要项收进“更多”，或者改成侧栏菜单。Two to seven. Beyond that, fold the rest under More or use a side menu.
计数Counts需要关注的数量用黄色小徽章跟在标签后面，0 时不显示。An attention count follows the label as a small yellow badge, hidden at zero.
地址URL选中的标签写进地址，刷新和分享后仍在同一标签。The active tab is in the URL, so refresh and sharing keep it.
和分段控件的区别Versus segments分段控件切换同一内容的显示方式（卡片 / 列表）；标签页切换不同内容。Segments change how the same content is shown (cards or list); tabs change the content.

属性Props

属性Prop类型Type默认Default说明Description
itemsArray—标签项。The tabs.
valuestring—当前选中项。The active tab.
onChange(value: string) => void—切换时回调。Called on change.
variant'underline' | 'pills''underline'下划线用于产品，pills 用于营销。Underline for product, pills for marketing.

无障碍Accessibility

键盘Keyboard左右方向键切换，Home / End 跳到首尾。Left and right arrows move; Home and End jump.
角色Rolesrole="tablist"、"tab"、"tabpanel"，选中项 aria-selected。role tablist, tab and tabpanel; the active tab has aria-selected.
